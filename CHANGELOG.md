# Release notes

## Android 7.0 (17) / iOS 5.7 (7) — pending release

Improved AI summary reliability.

- Show clearer messages when an AI summary cannot load.
- Keep the AI summary button working after closing and reopening a summary.
- Clear an earlier summary when requesting a new one.
- Set an explicit response limit for AI summaries.
- Disable diagnostic logging by default and redact provider authentication headers.

The existing Bible chapter navigation, reading history, Bible versions, and font
preferences are retained.
